# NetControl

Консольная утилита для анализа локальной сети, написанная на Go.

**Задачи проекта:**
- определить количество занятых и свободных IP-адресов;
- определить, какие IP заняты, а какие свободны;
- узнать и запомнить MAC-адреса подключённых устройств.

> Статус: активная разработка, ранняя стадия. Сейчас реализовано
> перечисление локальных сетевых интерфейсов и разбор IP-диапазона по CIDR.
> Реальное сетевое сканирование (ARP/ICMP) и хранение MAC-адресов — в планах.

## Требования

- [Go](https://go.dev/dl/) 1.26 или новее

## Сборка и запуск

```bash
git clone https://github.com/W0ndermaker/NetControl.git
cd NetControl
go build -o netcontrol .
```

## Использование

```bash
# справка
./netcontrol --help

# показать локальные сетевые интерфейсы
./netcontrol scan

# показать диапазон IP-адресов для сети
./netcontrol scan 192.168.1.0/24
```

## Структура проекта

```
main.go              — точка входа
cmd/                 — команды CLI (cobra)
internal/scanner/    — логика разбора сетей и вывода результатов
```

## Разработка

```bash
go vet ./...     # проверка
gofmt -l .       # форматирование (пусто = ок)
go test ./...    # тесты
go build ./...   # сборка
```
